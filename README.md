# Walkie Talkie: Offline Wi-Fi Push-to-Talk App for Android

**A free, open-source walkie-talkie app for Android that works without internet.** Phones on the same Wi-Fi network, or connected to one phone's hotspot, find each other in seconds and talk directly with end-to-end encryption. There's no mobile data, no account, no server and no ads.

Use it as a two-way radio, a home intercom or a push-to-talk (PTT) app for teams, at home, at work, at events or on a trip. If you searched for an offline walkie-talkie, a Wi-Fi intercom, a LAN voice chat or a hotspot walkie-talkie for Android, this is that app.

## Why this walkie-talkie app

- **No internet needed.** It works on a Wi-Fi network with no internet connection, or on a phone's hotspot with no signal.
- **Never uses mobile data.** Voice only travels over your local Wi-Fi, so there's nothing to pay and nothing to roam.
- **No sign-up.** No account, phone number, email or login. Open the app and talk.
- **Private.** Voice is end-to-end encrypted and never recorded or stored.
- **Tiny and clean.** About 60 KB, with no ads, no tracking and no third-party libraries.
- **Open source.** All the code is here under the MIT license. Read it, check what it does, build it yourself or improve it.

## Features

- **Push to talk (PTT).** Hold the big talk button to speak to everyone on your channel, and let go to finish.
- **Hands-free talking.** Slide the talk button up to lock it, then tap to stop.
- **16 channels.** Only people on the same channel hear you, so several groups can share one network.
- **Private one-to-one calls.** Hold a person's name to talk to them alone, whatever channel they're on.
- **Automatic discovery.** Everyone running the app on the same network appears within seconds. There are no IP addresses to type, no pairing and no QR codes.
- **Works on a hotspot.** No router? One phone turns on its hotspot and the others join it.
- **Up to 64 phones** on one network.
- **Clear voice.** 16 kHz wideband audio, with noise suppression and automatic volume control on phones that support them.
- **No missed messages.** Messages that arrive while you're talking, or while someone else is, are held and played right after (up to 30 seconds of audio).
- **Always on (optional).** Keeps listening when the app is closed, with a notification you can turn it off from.
- **Real radio feel.** Synthesized static, talk-permit chirps and roger beeps, which you can turn off. A transmission stops after 3 minutes, like the time-out timer on a real two-way radio.
- **Easy to read in the dark.** A pitch-black, high-contrast design that stays readable at the lowest screen brightness.
- **Fits any window.** Works on small phones, in split screen and in pop-up windows.

## What you can use it for

- **Home intercom.** Call between rooms and floors, or to the garden, over your home Wi-Fi.
- **Work and teams.** Staff in shops, restaurants, hotels, warehouses, offices, schools and on job sites can talk instantly over the building's Wi-Fi, without buying two-way radios.
- **Events.** Crews at weddings, concerts, conferences, churches and sports events can coordinate on the venue's Wi-Fi, even when the mobile network is overloaded.
- **Camping, hiking and trips.** One phone's hotspot makes a local network for the group, with no signal needed.
- **Internet outages.** If your router still has power but the internet is down, the app keeps working.
- **Kids and family.** A simple, free walkie-talkie for kids with old Android phones, with no accounts or chats with strangers on the internet.

The range is the range of your Wi-Fi network or hotspot. It's made for a home, a building or a group nearby, not for long distances.

## Download and install

1. Open the [latest release](https://github.com/AsifMinar/WalkieTalkie/releases/latest) on your phone and download the `.apk` file.
2. Open it. If Android asks, allow **Install unknown apps** for your browser or file manager.
3. Open Walkie Talkie and allow the **microphone** (to talk) and **notifications** (for background listening).
4. Do the same on every phone, connect them all to the same Wi-Fi or hotspot, and start talking.

## Troubleshooting: phones can't see each other

- **Check that every phone is on the same Wi-Fi network.** Phones on different networks, or one on Wi-Fi and one on mobile data, can't find each other.
- **Guest Wi-Fi and public networks** (hotels, cafés, airports) often block devices from seeing each other. Use one phone's hotspot instead; that usually solves it.
- **Check the channel.** To hear group messages, everyone needs to be on the same channel. Private calls work across channels.
- **Check that the radio is on** (power button at the top right).

## FAQ

**Does this walkie-talkie app work without internet?**
Yes. It only needs a local Wi-Fi network or a phone's hotspot. The network doesn't need to be connected to the internet.

**Does it use mobile data?**
No. The app only sends voice over Wi-Fi and never over mobile data.

**Does it need a SIM card, phone signal or Bluetooth?**
No SIM card or signal is needed, and it doesn't use Bluetooth. It works over Wi-Fi only.

**How far does it work?**
As far as your Wi-Fi or hotspot reaches. A router usually covers a home or a floor of a building; a phone's hotspot reaches less far, so stay fairly close.

**Can I talk to someone in another city, over the internet?**
No. Everyone has to be on the same local network. That's what keeps it offline, private and free.

**How many people can use it at once?**
Up to 64 phones on one network, split across 16 channels.

**Does it work on iPhone?**
No. It's for Android 12 and newer only.

**Is it free and open source?**
Yes. There are no ads, no in-app purchases and no subscription, and the full source code is on GitHub under the [MIT license](LICENSE).

**Is it an offline alternative to apps like Zello?**
Yes. Internet push-to-talk apps send your voice through their servers and need a data connection and an account. This app needs neither: voice goes straight from phone to phone on your own network.

**Can other people listen in?**
Voice is end-to-end encrypted, and private calls can only be heard by the person you call. But anyone on the same Wi-Fi who has the app can join your channel, so use it on networks you trust. See [Security and privacy](#security-and-privacy).

**Does it record my conversations?**
No. Audio exists only in memory while it plays. Nothing is saved, and nothing is backed up to a cloud.

**Can I hear messages when the app is closed?**
Yes. Turn on **Always on** and the app keeps listening in the background, with a notification you can turn it off from.

## How it works

Each phone announces itself with a small broadcast on the Wi-Fi network. Phones that hear it agree on encryption keys, then voice goes straight from phone to phone (peer-to-peer over UDP), encrypted separately for each listener. There's no server in between, and the app ignores anything from outside the local network.

## Security and privacy

**What the app protects:**

- **End-to-end encryption.** Every pair of phones agrees on its own keys (ECDH P-256, then HKDF-SHA256), and all voice is encrypted with AES-128-GCM. Each listener gets their own encrypted copy.
- **Forward secrecy.** New keys are made every session, so recorded traffic can't be decrypted later, even if a phone is lost.
- **Private calls** are encrypted for one person only. Nobody else can decrypt them, even with the app on the same channel.
- **Tamper and replay protection.** Altered, forged or replayed packets are rejected.
- **Key proof.** A phone must prove it holds its key before anyone sends it audio, so copied announcements can't redirect your voice.
- **Hardened network code.** Strict packet parsing, rate limits and memory caps. Tests fuzz the parser with hundreds of thousands of malformed packets.
- **Nothing is recorded or stored.** Audio exists only in memory while it plays. There's no cloud backup, and traffic never leaves your Wi-Fi network.

**Limitations to know about:**

- **Anyone on the same Wi-Fi with this app can join your channel and hear it.** There's no group password. Use it on networks you trust, or on your own hotspot.
- **Identities aren't verified.** Names can be faked, and someone who controls the network itself (for example the router owner) could intercept a connection.
- **Some information is visible on the network.** Names, channels and when someone is talking can be seen by others on the Wi-Fi. The voice itself stays encrypted.

## For developers

### Building from source

The app is built **without Gradle or Android Studio**, using the Android SDK command-line tools directly, by [`build.sh`](build.sh):

```
aapt -> javac -> ProGuard -> dx -> zipalign -> apksigner
```

#### Tools needed (Linux or WSL)

- JDK 17 (`javac`, `keytool`)
- An Android SDK platform jar (`android-34.jar`)
- [ProGuard](https://www.guardsquare.com/proguard) 7.4
- `aapt`, `dalvik-exchange` (dx), `zipalign`, `apksigner` on your `PATH`

If your tools are installed somewhere else, point the script at them:

```bash
export SDK_JAR=/path/to/android-34.jar
export JAVAC=/path/to/javac
export PROGUARD=/path/to/proguard.jar
```

#### Signing

Android only installs signed apps. The signing key is **not** in this repository. To build your own copy, create a key once:

```bash
keytool -genkeypair -keystore signing-key.jks -alias walkie \
  -keyalg RSA -keysize 4096 -validity 10000
```

Then save its password in a file named `signing.env` next to `build.sh`:

```bash
WT_KEYSTORE_PASS=your-password-here
```

Both files are listed in `.gitignore`, so they never get committed. Back them up: you need the same key to install future builds as updates.

An APK signed with your own key can't update an installed copy from the official releases. Uninstall that one first.

#### Build

```bash
./build.sh
```

The signed APK is written to `WalkieTalkie.apk`.

### Tests

The encryption, packet parser, trust rules, message queue and screen layout are plain Java, so they're tested on a desktop JVM with no phone needed:

```bash
bash tests/run-tests.sh
```

This needs JDK 11 or newer.

```
  AudioOut.java         Speaker output
  Sfx.java              Synthesized radio sounds
  Prefs.java            Saved settings
tests/                  Desktop tests (security, trust rules, network simulation, screen layout)
```
